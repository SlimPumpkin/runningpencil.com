삭제 요청 방법

① 앱에서 요청하기

로그인한 상태에서 앱의 설정 → 내 계정 → 회원탈퇴에서 계정을 삭제할 수 있습니다. 회원탈퇴 메뉴는 내 계정 화면 맨 아래에 있습니다.

회원탈퇴는 다시 로그인한 뒤 5분 안에 진행해야 합니다. 탈퇴 전에 로그인에 쓴 서비스와 러닝펜슬의 연결 해제를 시도하며, 이 단계는 건너뛸 수 있습니다.

메일에 적을 내용은 아래와 같습니다.

  • 로그인 방식: 내 계정 화면의 가입 수단과 연결된 계정

지원 이메일로 계정을 삭제한 경우 로그인에 쓴 서비스의 연결은 각 서비스 안내에 따라 직접 해제해 주세요.

지워지는 데이터

계정을 삭제하면 아래 데이터가 지워집니다.

  • 계정 정보(이메일, 표시 이름, 가입 수단, 연결된 계정, 약관 동의 기록 등)
  • 직접 올린 프로필 사진
  • 달린 기록과 GPS 경로
  • 뱃지
  • 공개하지 않은 코스(비공개·검수 대기 등)
  • 알림을 보내는 데 쓰는 기기 토큰
  • 계정 식별자가 든 요청 횟수 제한 기록
  • 위치정보 수집·이용·제공사실 확인자료

남는 데이터

계정을 삭제한 뒤에도 아래 데이터는 표에 적은 기간 동안 남습니다.

※ 둘러보기에서는 기록·코스·뱃지를 서버에 저장하지 않습니다.

일부만 지우기

계정을 남긴 채 일부만 지우려면 앱의 아래 메뉴를 이용해 주세요.

  • 내가 만든 코스: 코스 상세 화면의 ⋮(「더보기」) → 「코스 삭제」. 내가 만든 코스만 지울 수 있고, 다른 사람이 그 코스로 이미 받은 뱃지는 남습니다.
  • 한 코스의 내 뱃지와 기록: 코스 상세 화면의 ⋮ → 「뱃지 삭제」(그 코스의 뱃지가 있을 때) 또는 「기록 삭제」(뱃지가 없을 때). 그 코스의 내 기록 전부와 그 코스의 뱃지가 함께 지워집니다.
  • 내 뱃지와 기록 전부: 설정 → 「데이터 관리」 → 「뱃지와 기록 모두 삭제」
  • 직접 올린 프로필 사진: 「내 계정」 → 프로필 사진 → 「올린 사진 삭제」

위치정보 동의 철회

러닝펜슬이 서버에 저장하는 개인위치정보는 기록 중에 받은 달린 경로(GPS 경로)뿐입니다. 앱에는 위치정보 동의만 따로 끄는 설정이 없습니다. 아래 방법으로 위치정보 수집을 멈추거나 동의를 철회할 수 있습니다.

  1. 기기 설정에서 러닝펜슬의 위치 권한을 끕니다. 위치정보 수집이 멈추고, 이미 저장된 기록은 그대로 남습니다.
  2. 앱에서 뱃지와 기록을 지웁니다. 코스 상세 화면의 「뱃지 삭제」·「기록 삭제」는 그 코스의 기록(GPS 경로)과 뱃지를 함께 지우고, 설정의 「뱃지와 기록 모두 삭제」는 내 기록과 뱃지를 전부 지웁니다.
    3. {%- if site.data.company.support_email.size > 0 %}
  3. 지원 이메일로 「뱃지와 기록 모두 삭제」를 요청합니다. 달린 기록 전부와 뱃지 전부가 지워지고 계정은 유지됩니다. 본인 확인 뒤 지체 없이 처리하고 답장으로 알려 드립니다. 요청 방법은 삭제 요청 방법에 있습니다.
    4. {%- endif %}
  4. 회원탈퇴를 합니다. 달린 기록 전부(GPS 경로)와 확인자료가 계정과 함께 지워집니다.

위치정보 동의를 철회하면(2~4번) 해당 개인위치정보와 위치정보 수집·이용·제공사실 확인자료를 지체 없이 파기합니다.

위치정보 수집·이용·제공사실 확인자료는 달린 기록마다 하나씩 만들고(경로와 좌표는 담지 않습니다), 서비스를 이용하는 동안에는 6개월 동안 보관한 뒤 지웁니다.
